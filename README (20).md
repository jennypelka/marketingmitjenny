Kleine Pille mit Punkt für einen Status oder einen Hinweis über einer Überschrift.

**Varianten.** `mj-badge` (`wash`), `mj-badge--accent` (Pfirsich mit dunklem Text), `mj-badge--success`, `mj-badge--plain` ohne Punkt. 13px/600, `radius-pill`, funktioniert in beiden Themen.

**Der Nutzer liefert:** ein bis fünf Wörter, keine Satzzeichen.

Tokens: `wash`, `wash-fg`, `accent`, `success-bg`, `success-fg`, `radius-pill`.
